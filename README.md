# Kelly's Farm

Jogo de ação 2D desenvolvido em Unity com scripts em C#. O jogador se movimenta pelo cenário, dispara projéteis e enfrenta inimigos como zumbis, morcegos e criaturas de fogo.

O projeto reúne três fases, menu, animações, trilha sonora e efeitos de áudio. A experiência inclui controle de vidas, pontuação, surgimento de inimigos e chefes acionados conforme o avanço da pontuação.
